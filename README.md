# FinanceApp
 Simple finance app


#### How to build and run
##### Dependencies:
###### - Bazel 8.0.1+
###### - g++ 14.2.1+

##### From the package directory

```
cd package
```
##### Clean

```
bazel clean --expunge
```
##### Build

```
bazel build //...
```
##### And Run

```
bazel run //src:main
```
